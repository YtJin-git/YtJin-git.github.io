## Compositional zero-shot learning

Recognizing a familiar attribute in an unfamiliar combination with an object requires representations that transfer beyond the training compositions. My work investigates prompt learning and primitive representations for this setting.

### PMNQP · Primitive Memory Networks with Qualified Prompts

Combines qualified textual prompts and primitive memory to enhance attribute and object representations for compositional recognition.

[Source code](https://github.com/YtJin-git/PMNQP) · [Publication](https://doi.org/10.1109/TIP.2026.3748354)

### MPPE · Multi-Modal Prompts with Primitives Enhancement

Investigates multimodal prompt learning and primitive enhancement for compositional zero-shot learning.

[Source code](https://github.com/YtJin-git/MPPE) · [Publication](https://doi.org/10.1109/TCSVT.2025.3577246)
