# Yutang Jin's academic homepage
Built from [Academic Pages](https://github.com/academicpages/academicpages.github.io), based on Minimal Mistakes. Original template license and attribution retained.
## Edit and build
Edit _pages/*.md and _config.yml. Portrait: images/portrait.jpg.
Run bundle install, then bundle exec jekyll build.
GitHub Actions builds and publishes the site on pushes to main.
The original private CV PDF is not included.
